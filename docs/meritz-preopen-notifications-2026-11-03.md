# 22시 장전 검사·수동 체결 대조·알림 보완

## 원인과 변경

2026-11-03 한국 22시 알림은 주문 전 장운영 상태 검사에서 발생했다. 앱 주문 실행/접수 행이 없었으므로 실제 주문 API가 거절한 내역과 구분한다. 장전 상태를 004/012 코드만으로 제한했던 검사를 제거했다. 22시 자동주문과 22시 이후 장전 수동 API 주문은 상태 조회를 건너뛰고 주문의 실제 응답·경고·주문번호를 판정한다. 거래일·예약 시각·가격·예수금·보유수량·중복 주문 검사는 유지한다. 정규장 수동주문과 03시 재점검의 정규장 검사는 유지한다.

직접 입력한 체결이 있으면 가이드·T 추정보다 실제 체결 원본과 입력 수량·금액 대조를 먼저 수행한다. 일치할 때만 과거 확인 대기를 matched로 바꾸며 자산·T·체결을 다시 입력하지 않는다. onlyRecorded 경로는 신규 체결 입력을 수행하지 않는다. 실제 대조에서도 거래일의 입력 기록이 일치했고 수량·현금·평단·T·버전·체결 건수가 전후 동일했다.

과거 last_error를 페이지마다 토스트로 띄우지 않는다. 과거 알림은 알림함에서 확인하고 현재 요청 결과만 토스트로 보여준다.

알림 목록에 한국 날짜·시각, 상세에는 초 단위 시각·알림 의미·처리 내용 전체·확인할 사항을 표시한다. 과거 알림은 발생 당시 기록임을 구분한다.
